# pico8

My PICO-8 carts. One folder per cart, saved as `.p8` so everything (code, sprites, map, sound) is readable text.

## Getting Started

You need [PICO-8](https://www.lexaloffle.com/pico-8.php). Clone this repo, point PICO-8 at it with `-root_path`, then `cd` into a cart's folder and `load` it.

- `first-light/` the first cart: a sprite that moves and beeps
- `jams/` jam kit and jam entries

Playable builds are on itch.io and sh0ds.dev, not in here.
